#  PDF to Markdown Converter

A fast, lightweight desktop utility that transforms PDF files into clean, structured Markdown (`.md`) documents. Built with Python, `Tkinter`, and `pymupdf4llm` for instant CPU-based conversion without heavy dependencies.

##  Features
- **Lightweight & Fast:** Converts multi-page PDFs to Markdown in seconds with minimal RAM usage.
- **Dark & Light Mode:** Built-in theme toggle for comfortable viewing.
- **Smart Image Extraction:** Optionally extracts embedded PDF images into an auto-generated `<filename>_images/` directory and links them cleanly inside the Markdown output.
- **Standalone Executable:** Available as a portable `.exe` with no Python installation required.
